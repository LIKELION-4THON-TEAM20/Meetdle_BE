# 지하철 노선 데이터 (A11 이동시간 계산용)

ODsay 무료 한도(하루 30건)로는 역↔역 이동시간 표를 채울 수 없어서,

원본은 CP949였고, UTF-8로 바꿔 저장했다. 내용은 고치지 않았다.

## 알려진 한계 (MVP)
- 1~8호선은 **서울교통공사 운영 구간만** 들어 있다. 코레일 운영 구간(1호선 서울역 남쪽·청량리 북쪽, 3·4호선 경기 구간 등)은 없다.
- 9호선은 역간 **거리만** 있어서 소요시간은 거리로 추정한다.
- 실제 시간표가 아니라 표준 운행시간 기준이다 (명세 D06: 지역 계산은 일시와 분리).
